CommerceInsight Portfolio Blueprint

This artifact explains the upgraded project scope, business value, and technical architecture for a Junior Data Analyst portfolio piece targeting the 2026 North India job market.

Problem Statement

Retail leaders in North India need a dashboard that turns transaction CSVs into fast, region-specific decisions. This project demonstrates the ability to identify top-performing products, track weekly KPIs, and investigate regional anomalies like a sales drop in Punjab.

What was built

Interactive KPI dashboard
North India regional analytics
Punjab anomaly drill-down
SQL analytics views
Python ETL pipeline
Portfolio-friendly documentation

Architecture

  1. Data ingestion: Raw CSVs are loaded from data/.
  2. Preprocessing: Cleaned transaction records and engineered time features in scripts/data_pipeline.py.
  3. Analytics: SQL views in sql/queries.sql expose KPIs, North India trends, and Punjab weekly patterns.
  4. Visualization: scripts/streamlit_dashboard.py renders an interactive dashboard with filters, charts, and anomaly alerts.

Key recruiter messaging

  • Demonstrated ability to support a take-home dashboard exercise using CSV inputs and Python.
  • Focused on North India and Punjab, matching regional hiring expectations for the role.
  • Delivered both static analytics outputs and an interactive dashboard artifact.
  • Built a pipeline that can be extended with real-time or AI-powered dashboard features.
